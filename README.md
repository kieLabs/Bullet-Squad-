## GitHub Pages Deployment Instructions

1. Extract `BULLET-SQUAD-GAMERKIE.zip` and upload all files inside `BULLET-SQUAD/` to a public GitHub repository.
2. Ensure `.nojekyll` is present in the root directory.
3. Open **Settings > Pages** on GitHub, select **Deploy from a branch** (`main` / `root`), and click **Save**.
4. Open your live URL `https://<username>.github.io/<repo-name>/` to play!
